# Simple — presentación visual

Presentación web responsive del brief de marca y las decisiones de diseño del catálogo.

## Uso

Abre `index.html` en el navegador. No requiere instalación ni compilación.

La presentación consume las fotografías y fuentes existentes en `../catalogo/`, por lo que conserva una única fuente de assets para el catálogo y para esta pieza editorial.
